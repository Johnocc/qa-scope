## ⚙️ v1.1 변경 이력 (v1.0 → v1.1)

> 변경 사유: 멘토 피드백 "니즈-상품 매칭표가 이 과제의 관건" 반영. v1.0의 D2가 "정보 파악(절차)"만 보고 "맞는 상품을 권유했는가(결과)"를 못 봐서, 매칭표(정답지)가 채점에 들어갈 통로가 없었음.

| 변경 | v1.0 | v1.1 |
|---|---|---|
| **D2 적합성 정의** | 절차만 ("확인한 뒤 권유했는가") | **절차 + 결과** ("확인 + 매칭표상 적합한 상품 권유") |
| **D2 배점** | 5점 | **6점** |
| **D4 면책 배점** | 4점 | **3점** (D2 상향분 1점 양보, D영역 합계 30 유지) |
| **위험 플래그** | 5개 규칙 | **6개** (D2 '명백한 오류' 추가) |

→ D영역 합계 30점, 전체 100점, 18항목 **모두 그대로 유지**.

**v1.2 (정합성 점검 ③ 반영):** 목록 화면 상태 라벨 정의 추가(불완전판매 의심 / 저점수 / 정상). **"확인 요망"은 목업 임시값으로 PRD 근거 없어 제거.** 저점수 기준선 = 총점 **70점 미만**. (출처: 화면 목업을 만든 과거 채팅 확인 결과, "확인 요망"은 임의 추가값으로 확인됨)

**v1.3 (교차검증 ① 반영 — 배점 원복):** D2 배점 6→**5 원복**, D4 배점 3→**4 원복**. 사유: v1.1의 D2 상향은 "멘토가 관건이라 함 → 배점 가중" 및 "2.5점 회피"라는 **근거 약한 추론**이었음. 멘토는 배점이 아니라 **매칭표 데이터**를 요구했고(인터뷰 원문 확인), 소수점은 시스템이 환산·평균에서 이미 다루므로 회피 불필요. **D2의 "절차+결과" 재정의·위험플래그·매칭표 연동은 그대로 유지**(이건 멘토·법적 근거 있음). 배점만 v1.0 체계로 복귀해 과거 데이터 비교 안정성 확보.

**v1.3 보정:** N/A(해당없음) 처리 문구를 `N_A_매핑규칙_확정본.md` 기준으로 통일 — 권유 없으면 **D 전체(D1~D6)** N/A, 트리거는 "단순문의 유형"이 아니라 **"신규 권유가 실제 있었나"**. 버전 번호는 v1.3 유지(배점·항목·구조 변화 없음).

**v1.3 보정②:** D6 트리거 정밀화 — D1~D5는 *신규 판매*에만 ON, **D6는 유지·해지방어·승환 등 어떤 권유든 있으면 ON**(아무 권유도 없을 때만 D6도 N/A). 앞 보정의 "D1~D6 전체 N/A"는 "권유가 전혀 없는 상담"에 한정됨을 명확화. 배점·항목·구조 불변, v1.3 유지.

## 2. 항목별 상세

### 채점 방식 (전 항목 공통)
3단계 앵커 방식 — AI가 판단하기 쉽고 근거 제시가 명확함:
- **충족(만점)**: 행동이 명시적으로 확인됨
- **부분충족(50%)**: 시도는 있으나 불완전·불명확
- **미충족(0점)**: 행동이 없거나 잘못 수행됨
- 모든 채점에는 **대화 원문 인용(근거 문장)** 필수 → 상세 화면의 "점수 클릭 → 텍스트 점프" 기능과 연결

**앵커 (D2) — 절차 × 결과 3×3 게이트 매트릭스 (결과 판정은 니즈-상품 매칭표[하드 로드, 프롬프트에 전체 삽입]에 연동):**

- **절차** = {가입목적 · 재정상황 · 기존계약} 중 확인한 개수 (0~3개)
- **결과** = 매칭표상 🟢적합 / 🟡부적합(해롭진 않지만 더 맞는 게 있음) / 🔴명백한 오류(고객에게 해로움)

| 절차＼결과 | 🟢 적합 | 🟡 부적합(무해) | 🔴 명백한 오류(유해) |
|---|---|---|---|
| **3개 확인** | 충족(5) | 부분충족(2.5) | 미충족(0) + 위험플래그 |
| **1~2개** | 부분충족(2.5) | 부분충족(2.5) | 미충족(0) + 위험플래그 |
| **0개(절차 전무)** | 미충족(0) | 미충족(0) | 미충족(0) + 위험플래그 |

- **개수만 센다(항목별 가중 없음 — 사람·AI 재현성 우선).**
- **절차 0개면 결과가 적합이어도 미충족** (절차 없이 우연히 맞춘 것은 인정하지 않음 — v1.4의 "우연히 적합=부분충족" 규정 폐기).
- **🔴 명백한 오류는 절차와 무관하게 미충족 + 위험플래그(아래 규칙 6) 동반.**
  - 충족 예: 자녀 교육비 목적 + 안정적 저축 선호 → 저축성 상품 권유 (절차3 + 적합)
  - 명백한 오류 예: 곧 목돈이 필요한 고객(N8)에게 장기 비유동성 상품(P1·P4·P5) 권유

> **소수 점수 처리:** 5점 항목(D2·D3·D6)의 부분충족은 2.5점. 시스템이 환산·평균에서 이미 소수를 다루므로(대시보드 평균 예: 82.4) 그대로 합산하면 됨. 배점을 짝수로 바꿔 회피할 필요 없음.

> **D2 채점 핵심:** "물어봤는가(절차)"와 "맞는 상품을 줬는가(결과)"를 **모두** 본다. 절차만 완벽하고 결과가 틀리면 충족 아님(부분 또는 미충족). 결과 판정의 정답지는 **매칭표**다.

> **D6은 역방향 항목**: 위반 발견 시 0점 + **무조건 위험 플래그**. 단, D6는 권유가 조금이라도 있으면 **항상** 평가.
> **N/A(해당없음) 처리:** 신규 판매가 없는 상담은 **D1~D5**를 N/A 처리. 단 **D6(부당권유)는 유지·해지방어·승환 등 어떤 권유든 있으면 평가**하고, 아무 권유도 없을 때만 D6도 N/A → 적용 항목 배점만 분모로 100점 환산. **상세 규칙(2단계 트리거·유형별 기본값·유형 분류 단계·조건부 항목 A2·B2·C3)은 `N_A_매핑규칙_확정본.md`를 단일 기준으로 따른다.**
