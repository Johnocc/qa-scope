# 한빛생명 니즈-상품 매칭표 v1.0 (확정)
### D2 적합성 채점의 정답지 · 가상 보험사 '한빛생명'

> **상태:** 확정·고정 (강명수 팀장 프레임워크 컨펌 / 설계사 도메인 검증은 생략 — 자체 도메인 추론 기반).
> **이 표는 고정 정답지다.** 더미는 이 표의 시나리오에서 파생되며(거꾸로 아님), 채점 결과에 맞춰 표를 튜닝하지 않는다 — 튜닝하면 일치율이 무의미해짐(자기충족). 단, 골든셋 채점 중 사람이 **명백한 도메인 오류**를 발견하면 1회 수정 후 재고정 (버그 수정 ≠ 결과 끼워맞추기).
> **용도:** AI 채점 + 사람 골든셋 채점 **둘 다**의 정답지. 신규·보장 더미의 고객 상황은 이 표의 N1~N8 시나리오에서 가져오고, 권유 상품은 반드시 이 표 7개 안에서.

## 3. 매칭표 (채점 정답지)

### 판정 기준
- 🔴 **명백한 오류** (고객에게 실질적 해 → 위험플래그 6번) = 아래 셋 중 하나
  1. 원금보장 원하는데 → 원금손실 가능 상품(변액)
  2. 곧 목돈 필요한데 → 장기 비유동 상품(종신·연금·변액)
  3. 보장 목적(사망/의료/자녀)인데 → 보장 공백을 방치하는 순수 저축·투자·타목적 상품
- 🟡 **부적합** = 해롭진 않지만 같은 목적군 안에서 형태·예산이 덜 최적
- 🟢 **적합** = 니즈에 정확히 부합

### 시나리오별 매칭

| 니즈 | 🟢 적합 | 🟡 부적합 | 🔴 명백한 오류 |
|---|---|---|---|
| N1 한시적 사망보장·예산↓ | P2 정기 | P1 종신 (목적O, 보험료 과다) | P3 저축·P5 변액 (사망보장 공백) |
| N2 평생 사망보장·여력↑ | P1 종신 | P2 정기 (평생 아님) | P5 변액·P3 저축 (보장 목적 미충족) |
| N3 교육비 저축·원금보장 | P3 저축 | P4 연금 (노후용, 시점 안 맞음) | P5 변액 (원금손실↔원금보장 충돌) |
| N4 노후 연금·안정 | P4 연금 | P3 저축 (일시금↔연금흐름) | P5 변액 (안정↔손실) / P1 종신 (목적 다름) |
| N5 장기투자·손실 감수 | P5 변액 | P4 연금 (수익추구엔 보수적) | (거의 없음) |
| N6 의료비 대비 | P6 건강 | (동반가입 수준) | P3·P4·P5·P1 (의료보장 공백) |
| N7 자녀 보장 | P7 어린이 | P6 성인 건강(자녀특화 아님) | P1·P4·P5 (자녀목적 미충족) |
| N8 단기 자금(곧 목돈) | (보험엔 사실상 없음→예적금) | P3 저축 (단기엔 사업비로 손실) | P1·P4·P5 (장기 비유동→돈 묶임) |

> N8이 '명백한 오류'의 대표 케이스. 곧 쓸 돈인데 장기 상품에 묶으면 해지손실이 큼.
