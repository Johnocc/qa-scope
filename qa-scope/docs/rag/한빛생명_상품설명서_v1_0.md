# 한빛생명 상품설명서 (팩트시트) v1.0
**AI 채점 RAG 참조문서 — B1 정보 정확성·D 영역 채점 기준**

> **용도**: 상담사 발언의 정확성 검증용. 숫자는 가상이나 상품 간·문서 내 일관성 유지.  
> **기준일**: 2026년 6월 / **대상**: 한빛생명 주요 상품 7종 (P1~P7)  
> **주의**: 풀 법률 약관은 별도 문서(`한빛생명_가상약관_v1.0`) 참조.

## P1. 한빛 종신보험

| 항목 | 내용 |
|---|---|
| 정식 상품명 | 한빛 종신보험 (무배당) |
| 보장내용 | 사망 시 가입금액 전액 지급 (기본 1억 / 3천만·5천만·2억 선택 가능) |
| 재해사망 특약 | 기본보험금의 50% 추가 지급 |
| 보험료 예시 | 가입금액 1억 기준 / 40세 남성 월 182,000원 / 40세 여성 월 141,000원 (20년 납) |
| 보험기간 | **종신** |
| 납입기간 | 10년·20년·30년 납 선택 |
| 해지환급금 | 납입 3년 시 납입보험료의 **38%** / 납입 10년 시 **72%** / 납입 20년(완납) 시 **99%** / 완납 후 5년 경과 시 **107%** |
| 면책기간 | 없음 |
| 주요 면책사유 | ① 계약자·피보험자의 고의 사고 ② 계약일로부터 **2년 이내 자살** → 기납입보험료만 지급 ③ 전쟁·내란·폭동 |
| 청약철회 | 청약일로부터 **15일 이내** (보험증권 수령일 기준으로도 15일 미경과여야 함) |
| ⚠️ 채점 핵심 | 중도해지 시 납입액보다 **적게** 받을 수 있음. "원금 보장" 표현 사용 불가. 장기 유지 전제 상품. |

| 항목 | 내용 |
|---|---|

| 보장내용 | 만기 시 만기보험금 지급 (원금 + 공시이율 이자) / 보험기간 중 사망 시 기납입보험료의 **101%** 지급 |
| 보험료 예시 | 월 300,000원 또는 월 500,000원 선택 (예시 기준) |
| 보험기간 | 10년·15년 선택 |
| 납입기간 | 전기납 또는 일시납 |
| 해지환급금 | 납입 1년 시 **60%** / 납입 3년 시 **82%** / 납입 7년 시 **100%** / 만기(10년) 시 원금 + 이자 |
| 적용이율 | 공시이율 연 **3.0%** (변동 — 최저 보증이율 연 1.0%) |
| 면책기간 | 없음 |
| 주요 면책사유 | 고의·자해로 인한 사망 시 보험금 미지급 |
| 청약철회 | 청약일로부터 **15일 이내** |
| ⚠️ 채점 핵심 | 만기 원금보장이나 **7년 이전 해지 시 원금 손실 가능**. 단기 유동성 필요 고객에게 부적합. |

| 항목 | 내용 |

| 보험료 예시 | 월 300,000원 납입 / **50세 가입·10년 거치·종신연금 시 60세부터 월 약 145,000원 수령 예상** (N4 노후 시나리오 기준) |
| 보험기간 | 거치기간 10년 + 연금지급기간 (종신 또는 확정기간) |
| 납입기간 | 거치기간 내 전기납 |
| 해지환급금 | 납입 3년 시 **68%** / 납입 7년 시 **88%** / 거치 만료(10년) 시 약 **100%** |
| 적용이율 | 공시이율 연 **2.8%** (변동 — 최저 보증이율 연 0.5%) |
| 면책기간 | 없음 |
| 주요 면책사유 | 고의·자해로 인한 사망 |
| 청약철회 | 청약일로부터 **15일 이내** |
| ⚠️ 채점 핵심 | 거치기간 중 해지 시 원금 손실 가능. **노후 장기 자금 목적 전용**. 단기 자금 필요 고객 부적합. |

## P5. 한빛 변액유니버설보험

| 항목 | 내용 |
|---|---|
| 정식 상품명 | 한빛 변액유니버설보험 (투자형) |
| 보장내용 | 사망 시 기본보험금(5,000만원)과 펀드 적립금 중 **큰 금액** 지급 |
| 보험료 예시 | 기본 월 300,000원 (유연납: 월 100,000원~500,000원 범위 내 조정 가능) |
| 보험기간 | 종신 |
| 납입기간 | 최소 5년 이상 (유연납) |
| 해지환급금 | 펀드 수익률에 따라 **완전 변동** — 원금 이상·이하 모두 가능 |
| 투자위험 | ⚠️ **원금손실 가능. 최저 적립금 보증 없음** |
| 면책기간 | 계약일로부터 **1년 이내** 재해 외 사망 시 기납입보험료만 지급 |
| 주요 면책사유 | 고의, 2년 이내 자살, 전쟁·폭동 |
| 청약철회 | 청약일로부터 **15일 이내** |
| ⚠️ 채점 핵심 | "원금 보장" 표현 절대 불가. 단기 해지 시 사업비 공제로 손실 큼. 원금손실 감수 + 장기투자 목적 고객 한정. |

## P6. 한빛 건강보험

| 항목 | 내용 |
|---|---|
| 정식 상품명 | 한빛 건강보험 (무배당) |
| 보장내용 | ① 일반암 진단비 **3,000만원** / 소액암(갑상선암 등) **500만원** ② 뇌졸중·급성심근경색 진단비 각 **2,000만원** ③ 입원일당 **3만원/일** (180일 한도) ④ 수술비 종류별 **100만~500만원** |
| 보험료 예시 | 40세 남성 월 **74,000원** / 40세 여성 월 **63,000원** |
| 보험기간 | **80세 만기** |
| 납입기간 | 20년 납 |
| 해지환급금 | 저해약환급금형 기준: 납입 5년 시 **30%** / 납입 10년 시 **55%** / 20년 납 완납 시 **70%** |
| ⚠️ 면책기간 | **암 진단비: 계약일로부터 90일 이내 진단 시 미지급** |
| 주요 면책사유 | ① 90일 이내 암 진단 ② 고의·자해 ③ 기존 질병 (고지의무 위반 시 계약 해지 및 보험금 부지급) ④ 전쟁·방사능 |
| 청약철회 | 청약일로부터 **15일 이내** |
| ⚠️ 채점 핵심 | 암 90일 면책기간 반드시 안내. 기존 질병 고지의무 강조 필수. "가입하면 바로 보장" 표현은 **오정보(B1 위반)**. |

## P7. 한빛 어린이보험

| 항목 | 내용 |
|---|---|
| 정식 상품명 | 한빛 어린이보험 (무배당) |
| 보장내용 | ① 소아암 진단비 **1,000만원** ② 입원일당 **2만원/일** (120일 한도) ③ 골절·화상 치료비 **50만원** ④ 성장발육 이상 진단비 **200만원** ⑤ 상해 후유장해 최대 **5,000만원** |
| 보험료 예시 | 만 0~3세 기준 월 **28,000원** / 만 4~10세 월 **38,000원** |
| 보험기간 | 30세 만기 또는 100세 만기 선택 |
| 납입기간 | 20년 납 |
| 해지환급금 | 납입 5년 시 **50%** / 납입 10년 시 **75%** / 20년 납 완납 시 **95%** |
| 가입연령 | 출생일로부터 30일 이상 ~ 만 15세 이하 |
| ⚠️ 면책기간 | **소아암 진단비: 계약일로부터 90일 이내 미지급** |
| 주요 면책사유 | ① 90일 이내 소아암 진단 ② 고의·자해 ③ 기존 질병 및 선천성 질환 (고지 필수) |
| 청약철회 | 청약일로부터 **15일 이내** |
| ⚠️ 채점 핵심 | 선천성 질환·기존 질병 반드시 고지 안내. 소아암 90일 면책기간 설명 필수. |
